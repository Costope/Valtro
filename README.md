# Valtro – Compound Interest Calculator

Valtro is a lightweight, responsive Progressive Web App (PWA) designed for calculating compound interest and long-term savings plans. Built with a mobile-first approach, it provides a native application experience with offline support.

![Valtro Preview](./assets/preview-poster.png)

---

## Features

- **Progressive Web App:** Installable directly to the home screen on iOS and Android devices in standalone mode.
- **Offline Capabilities:** Powered by a Service Worker with a Network-First caching strategy and offline fallbacks.
- **European Number Formatting:** Full support for Eurozone standards via native `Intl.NumberFormat` APIs.
- **Modern User Interface:** Designed with precision to create a stylish, seamless user interface.

---

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **PWA Architecture:** Web App Manifest (`manifest.json`), Service Worker (`sw.js`)
- **APIs:** `Intl.NumberFormat`, `navigator.clipboard`, `navigator.share`

## Installation

### iOS (Safari)
1. Open the live URL in Safari.
2. Tap the **Share** button in the navigation bar.
3. Select **Add to Home Screen**.

### Android (Chrome / Edge)
1. Open the live URL in Chrome or Edge.
2. Open the browser menu (three dots).
3. Select **Install app** or **Add to Home screen**.
